ComfyUI 工作流提取器 v1.1

从 ComfyUI 生成的 PNG 中还原内嵌工作流（节点 · 提示词 · 参数 · 连接）。各分区可单独复制到剪贴板。图片在本机处理，不上传任何服务器。

把 PNG 图片拖到这里，或 点击选择
支持多选
提取功能适用的图片前提条件
  • 必须是 PNG 格式：ComfyUI 的 Save Image 节点只输出 PNG 并写入元数据；转成 JPG/WebP 的图不含这些块。
  • 须由 ComfyUI 的 Save Image 节点直接生成：若使用不写元数据的第三方保存节点、或生成时关闭了元数据写入，则没有。
  • 不能被外部重编码 / 编辑 / 压缩：复制、改名安全；用 Photoshop/Preview 另存、微信/QQ 压缩传输、或贴进拼图软件再导出，都会丢失 PNG 文本块（tEXt）。
  • 元数据是「生成该图时」的工作流，不是当前 ComfyUI 编辑器的实时状态。
  • 内嵌两路 JSON：workflow（编辑器格式，含节点坐标/widget/连线）与 prompt（API 格式，class_type+inputs，连线以 [源节点,输出序号] 表示）。两者都是完整可复现的工作流。
原理：ComfyUI 把工作流以 PNG 文本块（tEXt）写入图片；本程序解析这些块并还原成 JSON。桌面应用模式由 Python 直接读图与写回原目录；浏览器模式在页面内解析。
